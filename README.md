# Counterparty and Corporate Credit Risk Portfolio

Three independent Streamlit demos aligned with corporate counterparty risk and credit analysis.

- Counterparty Exposure and Limit Monitor: correlated Monte Carlo pricing, netting, EPE/PFE, and limit breach flags.
- Corporate Counterparty Scoring: SEC financial statement ratios and transparent Z double-prime screening.
- Credit Risk Dashboard: SEC-based receivables scale proxy and sector concentration view.

Projects 2 and 3 use a compact CSV snapshot derived from SEC EDGAR XBRL company facts (12 public issuers, 96 company-years). Project 1 uses synthetic illustrative trades, market assumptions, and limits. See each project README for assumptions and limitations.
